## 📝 Problem Statement

Given an array nums where each integer in nums appears **thrice** except one. Find out the number that has appeared only **once** .

### Example 1

<p>

**Input:** nums = [2, 2, 2, 3]</p><p>

**Output:** 3</p><p>

**Explanation:** The integers 3 has appeared only once.</p>

### Example 2

<p>

**Input:** nums = [1, 0, 3, 0, 1, 1, 3, 3, 10, 0]</p><p>

**Output:** 10</p><p>

**Explanation:** The integers 10 has appeared only once.</p>

### Constraints

- 1 <= n <= 3*10^4
- -2^31 <= nums[i] <= 2^31 - 1

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
